01

Empieza aquí

¿Qué es Repúblicas Unidas?

RRUU es una iniciativa ciudadana para hacer visible, útil y democrática la integración de Hispanoamérica. Empieza con problemas concretos y mantiene como horizonte una comunidad federal de repúblicas libres, si sus ciudadanos deciden construirla.

No pedimos fe en la meta final.

Pedimos evaluar el próximo paso por su utilidad, transparencia y respeto a la libertad.

Qué no es RRUU

No es un partido político, un gobierno paralelo ni una campaña para imponer una identidad única.

No pretende borrar las naciones existentes. Cualquier unión futura debe ser voluntaria, constitucional y ratificada democráticamente.

04

Gobernanza provisional

Primero practicamos la democracia que queremos defender.

El sistema distingue tres actos que no deben confundirse:

Apoyar

Indica que vale la pena investigar una prioridad. No aprueba un proyecto.

Consultar

Recoge preferencias y objeciones de manera pública. Todavía no es vinculante.

Votar

Toma una decisión bajo reglas aprobadas, padrón, quórum y escrutinio auditable.

05

Trabajo visible

Proyectos y expedientes públicos.

Cada Issue es un expediente. GitHub Projects los organiza sin reemplazar su historia.

Issue

Unidad mínima de registro: propuesta, tarea, investigación, reporte o decisión.

Proyecto

Iniciativa importante o continua con responsable, hitos y varias acciones relacionadas.

GitHub Project

Vista operativa que muestra estado, etapa y ciclo sin reemplazar los expedientes.

Proceso actual de una propuesta

  1. 1
    Registrar

    Cualquier persona abre un Issue con el problema, lugar, evidencia y primer experimento.

  2. 2
    Aclarar

    Se pide evidencia y se comprueba si ya existe un expediente relacionado.

  3. 3
    Clasificar

    Se determina si es tarea, decisión, investigación o iniciativa con alcance de proyecto.

  4. 4
    Revisar

    Se evalúan principios, riesgos, dependencias y condición de éxito.

  5. 5
    Incorporar

    Un proyecto aceptado recibe responsable, etapa y ciclo en el tablero.

  6. 6
    Ejecutar y verificar

    Se publican hitos y el resultado se compara con la condición de éxito.

¿Cuándo debe crearse un proyecto nuevo?

Sí: cuando la iniciativa es importante o continua, reúne varias tareas o participantes, requiere coordinación o mantenimiento, o debe formar parte visible de la hoja de ruta.

No: para una corrección editorial, un error aislado, una pregunta pequeña o una mejora de una sola entrega. Ese trabajo permanece como Issue o sub-issue del proyecto existente.

El número automático del Issue es el identificador público. No usamos una numeración paralela.

07

Democracia informada

Votar desde una aplicación no basta.

Una decisión digital solo será legítima cuando combine acceso, comprensión, deliberación, privacidad y auditoría.

Requisitos antes de una votación vinculante
  • Definición pública de quién puede votar.
  • Identidad verificable con mínima exposición de datos.
  • Informe neutral sobre alcance, alternativas, costos y riesgos.
  • Periodo de deliberación y mecanismo de apelación.
  • Quórum, umbral y fecha de cierre conocidos de antemano.
  • Escrutinio auditable y publicación de resultados agregados.
¿Cuándo incorporaremos Decidim?

GitHub mantiene hoy los expedientes y la ejecución. Sus reacciones indican apoyo, no votos vinculantes.

Probaremos Decidim después de completar dos consultas manuales y reunir 30 miembros recurrentes de al menos tres repúblicas, dos moderadores, un responsable técnico, reglas aprobadas y mantenimiento por doce meses.

El primer piloto combinará información, propuestas, deliberación, decisión y rendición de cuentas. La verificación de identidad y Elections solo se evaluarán después de auditarlo.

08

Repúblicas Abiertas

Publicar archivos no es lo mismo que abrir el poder.

RRUU busca convertir datos gubernamentales en evidencia comprensible, comparable y accionable para la vigilancia ciudadana.

  • Fuentes oficiales con fecha de verificación.
  • Metodología pública y reproducible.
  • Limitaciones y faltantes explicados.
  • Ruta para reportar errores y exigir correcciones.
