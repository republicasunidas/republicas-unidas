# Centro de documentación

## Problema

La narrativa, la gobernanza y los procedimientos de RRUU están distribuidos entre la landing, archivos del repositorio e Issues. Una persona nueva necesita una ruta coherente para comprender el proyecto y saber cómo participar.

## Alcance inicial

- Publicar un centro navegable en `/docs/`.
- Explicar propósito, método, principios y horizonte.
- Documentar la gobernanza provisional y la diferencia entre apoyar, consultar y votar.
- Documentar el proceso actual de propuestas y cuándo se crea un proyecto.
- Mostrar los expedientes activos y su relación con la hoja de ruta.
- Facilitar búsqueda, navegación móvil y enlaces a las fuentes versionadas.

## Próximo hito

Publicar el centro con la landing, validar búsqueda y navegación móvil, y realizar una prueba de comprensión con personas que no hayan participado en su diseño.

## Condición de éxito

Una persona nueva puede encontrar en menos de dos minutos qué es RRUU, cómo se toma una decisión, cuándo una propuesta se convierte en proyecto y dónde contribuir.

## Criterios de aceptación

- [x] Arquitectura de información y navegación por temas.
- [x] Búsqueda local de la documentación.
- [x] Proceso de propuestas documentado.
- [x] Criterios para crear proyectos documentados.
- [x] Enlaces a Issues, GitHub Project y fuentes abiertas.
- [ ] Publicación verificable en el dominio público.
- [ ] Prueba de comprensión con participantes externos.

## Cómo contribuir

Comenta términos ambiguos, información faltante o recorridos difíciles. Las correcciones pueden presentarse como pull requests vinculados a este expediente.
