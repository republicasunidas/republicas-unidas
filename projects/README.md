# Registro de proyectos RRUU

Los archivos de esta carpeta son el registro legible y versionado de los proyectos. Cada ficha debe contener como mínimo:

- enlace y número del Issue principal;
- estado del ciclo participativo;
- etapa de la hoja de ruta;
- problema y evidencia;
- responsable o necesidad de responsable;
- próximo hito verificable;
- condición de éxito;
- enlaces a deliberación y decisión.

Estados permitidos: `propuesta`, `revision`, `deliberacion`, `votacion`, `ejecucion`, `verificacion`, `completado`, `archivado`.

Etapas de ruta: `organizar`, `probar`, `abrir`, `conectar`, `decidir`.

## Cuándo entra una iniciativa al registro de proyectos

El número del Issue principal es el identificador público; no se mantiene una secuencia paralela. Se crea un proyecto cuando la iniciativa es importante o continua, reúne varias tareas o participantes, requiere coordinación o mantenimiento, o debe formar parte visible de la hoja de ruta.

Las correcciones, errores aislados, investigaciones pequeñas y mejoras de una sola entrega permanecen como Issues o sub-issues del proyecto correspondiente.
