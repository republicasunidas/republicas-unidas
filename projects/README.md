# Registro de proyectos RRUU

Los archivos de esta carpeta son el registro legible y versionado de los proyectos. Cada ficha debe contener como mínimo:

- código estable;
- estado del ciclo participativo;
- etapa de la hoja de ruta;
- problema y evidencia;
- responsable o necesidad de responsable;
- próximo hito verificable;
- condición de éxito;
- enlaces a deliberación y decisión.

Estados permitidos: `propuesta`, `revision`, `deliberacion`, `votacion`, `ejecucion`, `verificacion`, `completado`, `archivado`.

Etapas de ruta: `organizar`, `probar`, `abrir`, `conectar`, `decidir`.
