# Landing pública de RRUU

## Problema

RRUU necesita un punto de entrada comprensible y confiable que explique el propósito, muestre el trabajo real y permita participar sin presentar la meta federal como un acto de fe.

## Alcance inicial

- Publicar la identidad y narrativa provisional.
- Mostrar el registro de proyectos y su relación con la hoja de ruta.
- Conectar propuestas, evidencia, consultas y actualizaciones con GitHub Issues.
- Explicar la diferencia entre apoyo, consulta y voto vinculante.
- Mantener el código y la documentación bajo una licencia abierta.

## Próximo hito

Publicar el prototipo en `republicasunidas.org`, verificar su funcionamiento móvil y reemplazar el formulario demostrativo por una inscripción con consentimiento verificable.

## Condición de éxito

Una persona que no conoce RRUU puede explicar qué hace, identificar el próximo paso y abrir una propuesta o expediente público sin ayuda.

## Criterios de aceptación

- [x] Diseño responsive y accesible en versión inicial.
- [x] Repositorio público y licencia MIT.
- [x] Proyectos vinculados a Issues públicos.
- [x] Hoja de ruta vinculada a proyectos activos.
- [ ] Dominio `republicasunidas.org` sirviendo el sitio por HTTPS.
- [ ] Formulario de participación conectado a un sistema con consentimiento.
- [ ] Prueba de comprensión con participantes de al menos tres repúblicas.

## Cómo contribuir

Comenta problemas de claridad, accesibilidad o confianza; adjunta capturas y explica el dispositivo o contexto. Las mejoras de código pueden proponerse mediante pull requests vinculados a este expediente.
